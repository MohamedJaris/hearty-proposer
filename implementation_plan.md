# Romantic Proposal Website

A multi-page romantic themed website with blush pink theme, animated hearts, and an interactive proposal flow.

## Pages

1. **Home** - Blush pink, floating hearts, proposal text, Yes/No buttons (No runs away)
2. **Yes** - Thank you message + "Click for more" button  
3. **Gift** - Apology + picture placeholder + "Final click" button
4. **Birthday** - Full-screen birthday message

## Tech Stack

- React + Vite
- React Router for navigation
- Tailwind CSS for styling
- Framer Motion for animations
